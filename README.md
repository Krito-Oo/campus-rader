# 校园机会雷达 Campus Radar

> 计算机协会软件部 2026 年秋季纳新第二轮考核作品
> 面向在校学生（重点照顾新生）的「校园活动与机会」聚合小产品

## 解决什么问题

校园里比赛、讲座、招募、志愿活动的信息分散在不同渠道，时间、报名条件、面向人群各不相同，新生往往不知道哪些适合自己、哪些快截止了，也难分辨学生自发信息里夹杂的广告和可疑内容。
校园机会雷达把这些信息**集中整理、按状态组织、主动提醒**，帮用户用更低的判断成本发现和理解适合自己的机会。

## 运行方式

纯静态前端，无需后端、无需构建：

- 本地：直接用浏览器打开 `index.html`（或任意静态服务器）
- 线上：GitHub Pages 直接发布仓库根目录即可访问

数据保存在浏览器 `localStorage`（收藏 + 自主发布的内容），刷新/重开不丢失。

## 核心功能

1. **信息浏览与整理**：题目提供的 26 条模拟校园信息全部入库，按类型（竞赛/讲座/招募/学习/志愿/活动/学生发起/通知/资料）分类，标注来源（官方/学院/学生发布）。
2. **搜索与筛选**：关键词搜索 + 类型筛选 + 「新生友好」「只看可参与」「隐藏风险信息」开关。
3. **今日提醒与截止倒计时**：顶部提醒条自动汇总「今天进行」和「48 小时内截止报名」的信息；卡片上按紧急程度显示倒计时。
4. **双视图浏览**：卡片视图 / 时间线视图一键切换；时间线按日期分组（今天/明天/周X），当天高亮，时间未定的信息归入单独分组。
5. **收藏（想参加）→ 我的日程**：一键收藏，收藏抽屉按时间整理为个人日程，支持**一键复制日程文本**到备忘录/日历；临近截止标红。
6. **学生自主发布**：发布表单完整进入正常浏览流程，可被搜索、筛选、收藏；发布内容默认标记「待核实」。
7. **状态持久化**：收藏与发布内容存 localStorage，刷新后保留。

## 自主设计的实用/创新功能

1. **信息可信度提示**：对学生发布来源的信息做风险识别。例如编号 24「零门槛日结、要求加私人微信」被标记为**高风险**并列出判断依据；编号 25「标题是技术交流、正文是商家优惠链接」被标记为**疑似广告**。这是对「开放参与 vs 信息质量」问题的产品化回应。
2. **发布端风险自检**：把信息质量思路延伸到发布环节——填写发布内容时若命中「加微信 / 日结 / 押金 / 刷单」等高风险关键词，表单实时给出提示，引导发布者补充主办方、地点等可信信息。
3. **关联通知合并**：编号 09（训练营场地调整）自动关联到编号 01 并展示「最新通知」；编号 20（开发名额已满）关联到编号 03，避免用户按旧信息行动。
4. **不确定信息显性标注**：如「报名满员即止但时间未注明」（06）、「费用未提供」（12）、「场地待确认」（22）、「回放待上传」（04）等，单独以提示框呈现，不编造题目未给出的信息。
5. **时间锚点设计**：按题目要求以 2026-09-19 为「今天」，所有「今天进行/已截止/倒计时」状态围绕该锚点计算，保证演示和评审时状态稳定一致（见 `data.js` 中 `TIME_ANCHOR`）。

## 对题目材料中发现并处理的问题

- 24、25 号为学生发布但内容可疑 → 风险标记 + 默认折叠进「隐藏风险信息」开关，而非直接删除（保留信息但降低误导）。
- 19 号报名已截止但允许候补 → 不显示「已截止不可参与」，标注「可候补入场」。
- 07、15 号存在「登记 ≠ 最终提交」的两个时间节点 → 单独提示，避免误解。
- 09、20 号是补充通知而非独立活动 → 关联到原信息，原信息卡片显示「🆕 有更新」。
